# Checkout Shipping Plan

소스: PROJ-123 (web-ui 결제 화면 배송비).

## T-1 무료배송 기준을 50,000원으로 올린다

**목표** — 주문 금액이 50,000원 이상일 때만 배송비가 0원이다.

**범위** — 포함: `fee.py`의 기준값, 경계값 테스트. 제외: 화면 문구.

**AC**
- 49,999원 주문의 배송비는 3,000원이다.
- 50,000원 주문의 배송비는 0원이다.

**검증** — `python3 -m unittest -v`

**의존성** — 없음

## T-2 쿠폰 적용 뒤 금액으로 무료배송을 판정한다

**목표** — 무료배송 판정은 쿠폰을 뺀 금액 기준이다.

**범위** — 포함: `shipping_fee`, `amount_due`, 테스트. 제외: 쿠폰 발급.

**AC**
- 32,000원 주문에 쿠폰 5,000원이면 판정 금액은 27,000원이고 배송비는 3,000원이다.
- 60,000원 주문에 쿠폰 5,000원이면 배송비는 0원이다.

**검증** — `python3 -m unittest -v`

**의존성** — 없음 (AC 금액은 기준이 30,000원이든 50,000원이든 같은 결과)
